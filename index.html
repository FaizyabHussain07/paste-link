Frequently Asked Questions

Is PasteLink free?

Yes, 100% free. No registration required.

Do I need an account?

No account needed for privacy.

How secure is PasteLink?

We use SHA-256 for passwords and auto-expiring databases.

What is burn-after-read?

Text self-destructs after the first view.

Are passwords stored?

We only store a cryptographic hash. We cannot read it.

How long can a paste remain available?

Between 10 minutes and 7 days.

Can I share code snippets?

Yes, perfect for code.

Can I use it on mobile?

Yes, fully mobile responsive.

Is my data encrypted?

Yes, via HTTPS and secure Redis.

Does PasteLink track users?

Only basic, anonymized product stats. No personal info.
